AI 短影片提示詞產生器
← 回到工具

操作手冊

AI 短影片提示詞產生器把一句話的畫面構想，優化成適合 OpenAI Sora、Google Veo、Runway 或可靈 Kling 使用的短影片生成提示詞。填一次主題、場景、秒數與鏡頭／風格設定，四個目標模型分頁共用；可以直接複製組成結果，也可以串接你自己的語言模型取得中英對照的正式提示詞。

四個目標模型分頁的差異

Sora
OpenAI Sora

一段完整的英文敘述句，把鏡頭運動、動作與氛圍自然融入描述中，不需要參數語法；Sora 目前一般可生成約 5～20 秒的影片。

Veo
Google Veo

依 Subject（主體）／Context（場景）／Camera（鏡頭運動）／Style（風格）／Ambiance（氛圍）分行陳述，這是 Google 官方建議的 Veo 提示詞寫法；一般常見時長約 5～8 秒。

RW
Runway

逗號分隔的英文關鍵詞組，鏡頭運動標籤放在最前面並以方括號包住（例如 [orbiting camera movement], ...），結尾附上時長與長寬比；Runway 常見時長約 5～10 秒。

Kling
可靈 Kling

中文為主的敘述句（可靈原生支援中文提示詞），鏡頭與氛圍詞彙置於句末；可靈常見時長為 5 秒或 10 秒。

操作步驟

  1. 先套用一個「範例」快速看懂欄位怎麼填（內建 5 種不同類型主題：產品展示、自然風景空拍、人物敘事、美食料理、科幻／奇幻場景），或直接從空白開始
  2. 在「主題／主體動作」填入畫面的核心內容（必填），並在「場景／地點」補充環境描述（建議填寫）
  3. 視需要選擇秒數、鏡頭運動、影片風格、光線氛圍、情緒氛圍、長寬比——這些設定四個目標模型分頁共用，只需要填一次
  4. 可選填「音效／配樂提示」（部分平台如 Veo3 支援音訊生成）與「不希望出現的元素」
  5. 在最上方選一個目標模型分頁（Sora／Veo／Runway／Kling）
  6. 按「🔧 組成提示詞」，下方會出現關鍵字組裝結果，可按「複製提示詞」直接使用
  7. 若想取得正式的中英對照提示詞（主題與場景文字經過翻譯與潤飾，並依各平台慣例調整格式），展開「送給 AI 優化」面板的「API 連線設定」填入自己的金鑰，按「🚀 送給 AI 優化」
  8. 滿意的結果可以在下方「已儲存的提示詞」取名儲存，之後隨時載回來或下載成 .txt 檔
切換目標模型分頁不會清掉主題、場景與鏡頭設定——這些欄位是四個分頁共用的；但每個分頁各自的「組成結果」與「AI 優化結果」會分開保留。
「秒數」只是各平台常見時長的參考選項，實際各服務支援的時長會隨版本調整；貼上提示詞後，仍建議依你使用的服務當下介面實際能設定的時長為準。

「組成提示詞」與「送給 AI 優化」有什麼不同

🔧 組成提示詞是純前端的關鍵字組裝，不需要 API 金鑰、不會連網：把你填的主題與場景文字（保留原始語言）＋鏡頭運動／風格／光線／情緒標籤（已經是對應的英文或中文片語）依各分頁格式組合成一份草稿，方便快速預覽結構，但主題與場景文字本身不會被翻譯。

🚀 送給 AI 優化會把主題、場景與鏡頭設定送給你設定的語言模型，由 AI 把整段內容翻譯、擴寫並依目標平台的慣例調整格式，輸出中英對照（Kling 分頁則是「中文說明＋可靈中文提示詞＋English Prompt」）的結果——這才是真正可以直接貼給影片模型使用的正式提示詞。

如果只是想快速看一下關鍵字組合，用「組成提示詞」就好；真的要拿去生成影片，建議走「送給 AI 優化」取得完整翻譯過、符合平台慣例的提示詞。

已儲存的提示詞

「已儲存的提示詞」是一個留在瀏覽器裡的紀錄清單，按「儲存」不會下載任何檔案，只是把目前分頁已組成的提示詞（連同 AI 優化結果，若有）存成一筆有名字的紀錄。

  1. 在儲存名稱欄位打一個好記的名字（留白會自動取名），按「儲存」
  2. 清單中每一筆紀錄可以「載入」（會自動切換回對應的目標模型分頁並覆蓋欄位）、「複製」、「下載 .txt」或「刪除」
  3. 取相同名字再按一次「儲存」會詢問是否要覆蓋既有紀錄
「儲存」＝存進這台瀏覽器的清單；「下載 .txt」才會真的產生一個檔案到你的下載資料夾。兩者是分開的動作。

送給 AI 優化（選用，需自備 API 金鑰）

填好主題、場景與鏡頭設定之後，可以直接在本工具呼叫你自己的語言模型 API，取得針對目前分頁模型優化過的中英對照提示詞。

  1. （選填）若你已經有一段既有的影片提示詞或腳本片段，想針對它做修改或補充，可以貼到「既有腳本／提示詞補充」欄位——AI 會以這段既有內容為基礎進行補充修改，並盡量保留原本的核心，此時「主題」可改填「想調整或加入的內容」，不需要重新完整描述畫面
  2. 展開「API 連線設定」，選擇服務商（Claude／OpenAI／Gemini／OpenRouter），填入你自己申請的 API 金鑰；模型欄有預設值，也可以自行改成你想用的模型 ID
  3. 按「🚀 送給 AI 優化」
  4. 優化結果會顯示在「AI 優化結果」區塊，可按「複製 AI 結果」使用
「既有腳本／提示詞補充」只會影響「送給 AI 優化」這一步，不會影響純前端組裝的「組成提示詞」；留空的話行為跟原本一樣，完全以「主題」與「場景」等設定產生全新提示詞。
API 金鑰要自己到各服務商網站申請，使用時依你與該服務商的方案計費，本工具不會向你收費，也不會經手你的金鑰——金鑰只存在你這台電腦的瀏覽器，且直接連到服務商官方 API，不會經過本工具以外的任何伺服器。

隱私說明

  • 你填寫的主題、場景與鏡頭設定、組成的提示詞與「已儲存的提示詞」清單都只存在自己瀏覽器的 localStorage，關閉分頁後下次打開仍會保留，但不會傳送到任何伺服器；換一台電腦或清除瀏覽器資料就會不見，請自行用「下載 .txt」備份重要內容
  • 複製提示詞後，貼到哪個影片生成服務、該服務如何處理這些文字，就依該服務自己的隱私政策規範，與本工具無關
  • API 金鑰同樣只存在瀏覽器的 localStorage；按下「送給 AI 優化」時，主題與鏡頭設定會直接連線送到你選擇的服務商官方 API，不會經過本工具作者或任何第三方伺服器

使用警語

請注意：
  • 本工具的核心功能是把你的畫面構想組織成結構化提示詞；只有你主動填入 API 金鑰並按下「送給 AI 優化」時才會呼叫語言模型，不使用這項功能也能取得關鍵字組裝結果
  • 請勿在任何欄位輸入真實個資、公司機密、他人受著作權保護的內容，或不希望被 AI 服務留存的敏感資訊
  • AI 優化結果可能包含錯誤或不精準的描述，貼給影片模型前請自行檢查；實際生成的影片內容、可用時長與品質仍取決於你使用的影片生成服務
  • 使用「送給 AI 優化」功能所產生的 API 費用由你與所選服務商的方案自行負擔，本工具不會向你收費
